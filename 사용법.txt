개인 PC로컬환경에서 제작되어 경로 및 커서에서 학습이 필요합니다.



================================================================================
                         영수증 자동화 시스템 사용법
================================================================================

【 개요 】
영수증 이미지를 분석하여 날짜, 시간, 결제처, 금액을 자동 추출하고,
규칙에 맞는 파일명으로 변환하여 저장하는 프로그램입니다.

파일명 형식: YYMMDD_HHMMSS_결제처_금액_메모.확장자
예시: 260123_124639_남만부대찌개_30000_식비.jpg


================================================================================
【 사용 순서 】
================================================================================

[1단계] 영수증 파일 준비
────────────────────────────────────────────────────────────────────────────────
• uploads 폴더에 영수증 이미지 파일을 넣습니다.
• 경로: C:\Users\joosu\Desktop\receipt-automation\uploads
• 지원 형식: PNG, JPG, JPEG, GIF, BMP, TIFF, PDF


[2단계] Flask 서버 실행
────────────────────────────────────────────────────────────────────────────────
• 터미널(명령 프롬프트)에서 아래 명령 실행:

  cd C:\Users\joosu\Desktop\receipt-automation
  python app.py

• 서버가 실행되면 아래 메시지가 표시됩니다:
  [영수증 자동화]
    uploads 폴더: ...
    output 폴더: ...
    
• 서버 종료: Ctrl+C


[3단계] Cursor에서 영수증 분석
────────────────────────────────────────────────────────────────────────────────
• Cursor 채팅창에서 "분석해줘" 입력
• Cursor가 uploads 폴더의 이미지를 읽고 분석합니다.
• 분석 결과는 analysis_results.json 파일에 자동 저장됩니다.

※ 새 영수증을 추가할 때마다 이 단계를 반복해야 합니다.


[4단계] 웹앱에서 확인 및 수정
────────────────────────────────────────────────────────────────────────────────
• 브라우저에서 접속: http://127.0.0.1:5000

• "폴더 스캔" 버튼 클릭
  → uploads 폴더의 파일 목록을 불러옵니다.
  → 분석 결과(JSON)가 자동으로 로드됩니다.

• 슬라이드 형식으로 각 영수증 확인
  - 날짜 (YYMMDD): 예) 260123
  - 시간 (HHMMSS): 예) 124639
  - 결제처: 예) 남만부대찌개
  - 비용: 예) 30000
  - 사용자 작성란: 예) 식비, 주차비, LPG 주유 등

• 필요시 데이터 수정 후 "다음" 버튼으로 이동

• 모든 영수증 확인 후 "리스트 보기" 클릭


[5단계] 파일 저장
────────────────────────────────────────────────────────────────────────────────
• 리스트 화면에서 변환될 파일명 확인
• "한 번에 저장" 버튼 클릭
• 저장 완료 메시지와 함께 output 폴더 경로가 표시됩니다.
• 저장 경로: C:\Users\joosu\Desktop\receipt-automation\output

receipt-automation/

│   ├── app.js
│   └── style.css

├── output/                 # 저장된 파일 출력 폴더
└── venv/                   # Python 가상환경


================================================================================
【 웹앱 버튼 설명 】
================================================================================

• 폴더 스캔     : uploads 폴더의 파일 목록 불러오기 + 분석 결과 자동 로드
• 결과 불러오기 : 현재 파일의 분석 결과만 다시 불러오기
• 전체 불러오기 : 모든 파일의 분석 결과 다시 불러오기
• 리스트 보기   : 저장할 파일 목록 미리보기
• 이전/다음     : 슬라이드 이동
• 슬라이드로 돌아가기 : 리스트에서 슬라이드 화면으로 복귀
• 한 번에 저장  : output 폴더에 파일 저장


================================================================================
【 주의사항 】
================================================================================

1. 서버가 실행 중이어야 웹앱을 사용할 수 있습니다.

2. 새 영수증을 추가하면 반드시 Cursor에서 "분석해줘"를 입력하여
   analysis_results.json을 업데이트해야 합니다.

3. 분석 결과가 정확하지 않을 수 있으니 웹앱에서 반드시 확인 후 저장하세요.

4. 저장된 파일은 output 폴더에 복사됩니다. (원본 파일은 유지됨)

5. 같은 파일명이 이미 존재하면 자동으로 번호가 붙습니다.
   예) 260123_124639_남만부대찌개_30000_식비_1.jpg


================================================================================
【 문제 해결 】
================================================================================

Q. 웹앱에 접속이 안 됩니다.
A. 터미널에서 python app.py가 실행 중인지 확인하세요.

Q. 분석 결과가 표시되지 않습니다.
A. Cursor에서 "분석해줘"를 입력하여 분석을 먼저 수행하세요.

Q. 데이터가 밀려서 표시됩니다.
A. Cursor에서 uploads 폴더 파일을 다시 분석해달라고 요청하세요.
   예) "uploads 폴더 파일 다시 분석해서 JSON 만들어줘"

Q. 서버 실행 시 에러가 발생합니다.
A. 가상환경 활성화 후 실행하세요:
   venv\Scripts\activate
   python app.py
